**Elite Critical Minerals** is an advanced AI & Data Science project focused on analyzing global critical mineral datasets.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/USERNAME/ELITE-CRITICAL-MINERALS.git
```

Go into project

```bash
cd ELITE-CRITICAL-MINERALS
```

Install requirements

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

Launch Notebook

```bash
jupyter notebook
```
